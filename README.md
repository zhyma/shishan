# ShiShan

- 设计哲♂学：一个野路子码农在无人在意的角落拉了坨大的，临走之前还用脚尖踢起点地上的土来试图把它盖住。路过的看看上面盖着的土就得了，没必要真的品鉴。正所谓“石山有路勤为鲸，雪海无涯苦做粥”。

一个 VS Code 扩展，用来“控制 Python 脚本的显示”：

- 自动折叠 `import` 语句和函数/类内部的代码；
- 只保留整行注释、三引号文档注释和 `def ...()` / `class` 函数签名，函数内部的注释也保留；
- 注释行下方保留一个折叠小三角，点击即可展开该注释对应的代码段落；
- 也可一键在“骨架视图”和“完整代码”之间切换。

## 使用效果

打开任意 `.py` 文件后，扩展会自动折叠成类似下面的骨架：

```python
import os

# 项目配置区
def load_config():
    """读取配置文件
    包含环境变量与默认值
    """
    # 读取配置文件
    # 解析 JSON

class Worker:
    # 工作线程池
    def start(self):
        # 逐个启动
        # 等待完成
    def stop(self):
        # 停止并清理

def main():
    # 入口逻辑
    # 输出结果
```

每一行注释后面的小三角就是折叠点：代码被收进注释下方，点击三角即可展开。

## 运行与调试

1. 打开本文件夹；
2. 在 VS Code 中按 `F5` 启动“Extension Development Host”；
3. 在扩展开发窗口中打开任意 `.py` 文件（仓库里也准备了 `sample/demo.py`）；
4. 文件打开后自动折叠；按 `Ctrl+Alt+S`（macOS 为 `Cmd+Alt+S`）切换骨架视图。

## 命令

| 命令 | 说明 |
| --- | --- |
| Python 骨架视图：折叠 / 展开 | 在当前 Python 文件中切换骨架模式 |
| Python 骨架视图：折叠全部 | 只显示注释、文档注释与 def/class 行 |
| Python 骨架视图：展开全部代码 | 恢复显示全部代码 |

## 设置

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| `pythonSkeleton.autoFoldOnOpen` | `true` | 打开 Python 文件时自动执行折叠 |
| `pythonSkeleton.showClassLines` | `true` | 是否把 `class` 行也保留为可见行 |

## 实现原理

扩展注册了一个 Python 语言的 `FoldingRangeProvider`：

1. 把“整行注释、三引号文档注释、`def`/`class` 行”之外的所有代码切成若干连续代码段（折叠后每段之间保留一个可见空行）；
2. 每段生成一个折叠范围，并尽量把折叠起点锚定在可见行上：
   - 代码段前面是注释 → 小三角落在最后一条注释行，点击展开其下方代码；
   - 代码段前面是 `def`/`class` → 小三角落在函数名/类名行；
3. 打开 Python 文件时执行一次 `editor.foldAll`，即得到“只显示注释和函数名”的骨架视图；
4. 状态栏显示骨架状态，点击可切换。

## 已知限制

- 行内注释（代码行后面的 `#`）会随代码一起折叠；
- 单行模块级代码（例如结尾只有一个 `main()` 调用且前面没有注释）会保留显示；
- 装饰器行会保留显示（编辑器折叠无法隐藏折叠范围的起点行）；
- 多行三引号字符串都会整体保留显示（无论是否作为文档注释使用）；
- 三引号字符串使用“引号出现次数奇偶”的启发式识别，极少数边界情况可能误判。
